App Screen Layout

Which screens should the app have? Here's my proposal based on the program structure.

Core Screens
1

Today's Workout (Home)

Shows what day you're on (e.g., "Day 2 — Week 1, Cycle 3"), lists exercises with target sets/reps/weight. Tap an exercise to start logging. Guided mode: walks you through each exercise in order with a rest timer between sets.

2

Active Exercise

Shows current exercise, set number, target reps, weight. Big "Complete Set" button. For AMRAP (black) exercises: log actual reps per set. Rest timer auto-starts after each set. Option to adjust weight mid-exercise (drop sets for accessories).

3

Progress

Charts for each compound lift over time (weight x cycles). Current working weights at a glance. PR history and cycle success/fail tracking per exercise.

4

History

Past workouts by date. Tap into any session to see what you lifted. Useful for reviewing performance across a cycle.

5

Settings

Set starting weights, rest timer duration (default 1-4 min), weight increments per exercise, current cycle/week position, unit preference (lb/kg).

Navigation

Bottom tab bar: Today | Progress | History | Settings

"Active Exercise" is a modal/fullscreen overlay launched from Today's Workout.
